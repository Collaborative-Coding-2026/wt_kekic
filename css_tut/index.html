Overflow

Overflow is a property that sets the desired behavior when content does not fit in the parent element box; there are five states:

  • overflow: visible
  • overflow: hidden
  • overflow: clip
  • overflow: scroll
  • overflow: auto


Our next part is display properties. The display property tells us whether or not an element is displayed and how. There are block level displays, which start on a new line and take up the full width available, and there are in line elements, which don't start on a new line and only use what is needed.
