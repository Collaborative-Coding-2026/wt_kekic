Description List - Fighting Game Terms

Normal
A normal move or normal attack (often simply called a normal) is any attack performed using a single button press, without moving the joystick and usually without being in midair.
Juggle
A juggle describes the state during a combo in which the victim is hit multiple times while they are in mid-air (typically by a grounded opponent in this context).
Negative Edge
Use of button release in place of button press within a command input sequence; most Capcom fighting games allow special and super moves to be performed with this method.
