# 🚀 2026 WT Collaborative Coding: JavaScript Platformer
Author : Madison Kekic
## Description
In this project, I build a platformer game in JavaScript from scratch. This repository includes my process of learning HTML, CSS, and Javascript- all of which are preliminaries for building the final product.
### Files Included
#### 📂 html_tut
HTML is used to create the structure of a website; to get started learning HTML I used BroCode's guide to learning HTML and CSS for [beginners](https://www.youtube.com/watch?v=HGTJBPNC-Gw&list=PLZPZq0r_RZOPP5Yjt6IqgytMRY5uLt4y3)
This guide covers several core HTMl concepts and tools including:
* Using the [live server extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) to see updates to the website in real time
* Basic HTML tags including:
    * !DOCTYPE html: Declares this is an html document
    * html: Represents the root element of an html page
    * head: Contains information about the webpage including title and favicon
    * body: Contains visible content
    * h1, h2 ... : Headings Tag
    * p: Paragraph Tag
    * hr: Horizontal line tag
    * br: Line break tag
    * pre: Preformatted text tag
    * !--: Comment tags
  * Creating Hyperlinks
  * Including Images
  * Including Audio
  * Including Videos
  * Including a Favicon
  * Formatting Text
  * Defining and Differentiating Spans & Divs
  * Adding Tables
  * Adding Buttons
  * Creating Forms
  * Adding Headers and Footers
The index.html file contained in this html_tut folder contains an implementation of all the concepts listed above. There is a second file- lyrics.html, which is a more refined application of early concepts (up to including images)
 
#### 📂 css_tut
CSS is used to change the design of a website; to learn CSS, I followed the same [guide](https://www.youtube.com/watch?v=HGTJBPNC-Gw&list=PLZPZq0r_RZOPP5Yjt6IqgytMRY5uLt4y3).
This guide also covers several CSS topics including:
* Background and font colors
* Changing and importing fonts
* Applying borders
* Applying Margins
* Applying Floats
The index.html file contained in the css_tut provides a structure for implementing the CSS concepts described above. The style.css file is a stylesheet implementing the concepts.
